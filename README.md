# 🏠 iList - 装修已购清单

记录每一件为新家选购的好物，支持多图上传和发货状态管理。

**在线访问：** https://g.hijoe.net/iList/

---

## 功能特点

- **商品管理** — 添加商品名称、分类、单价、数量、购买渠道、备注等信息
- **多图上传** — 每个商品最多上传 9 张图片，支持多选，自动压缩存储
- **发货状态** — 四种状态（待发货 → 已发货 → 已收货 → 已完成），点击状态角标一键切换
- **分类筛选** — 按分类（家具/家电/灯具/建材/软装/厨房/卫浴/其他）快速筛选
- **搜索功能** — 按商品名、备注、渠道关键词搜索
- **数据导出/导入** — JSON 格式备份，换设备也能轻松迁移
- **本地存储** — 所有数据保存在浏览器 localStorage，刷新不丢失

---

## 页面说明

- **清单页** (`index.html`) — 首页，展示所有商品卡片，支持搜索、筛选、导出导入
- **添加页** (`add.html`) — 点击顶部「添加商品」进入，填写信息后保存自动返回清单

---

## 技术栈

- 纯原生 HTML + CSS + JavaScript，无任何依赖
- 图片以 base64 形式压缩存储在 localStorage 中
- 使用 GitHub Pages 托管

---

## 数据备份

所有数据存储在浏览器本地。如需换设备或清浏览器缓存，请先点击「导出数据」下载备份文件（JSON 格式），之后在「导入数据」中选择该文件即可恢复。
